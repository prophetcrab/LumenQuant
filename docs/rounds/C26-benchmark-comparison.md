# 迭代记录 C26：基准对比（alpha / beta / 信息比率）

## 动机

之前回测只报策略收益和一个粗糙的"基准对比"（首尾价格比）。
这掩盖了一个根本问题：**在上涨市里，任何多头策略看起来都赚钱**。

真正该问的是：策略跑赢买入持有了吗？超额收益来自选股/择时（alpha），
还是仅仅因为承担了更高的市场暴露（beta）？

## 实现

`app/modules/backtest/benchmark.py`，基准为同一标的的买入持有：

| 指标 | 计算 |
|---|---|
| 超额收益 | 策略收益 − 基准收益 |
| Beta | cov(策略,基准) / var(基准) |
| Alpha | (均值策略 − beta × 均值基准) × 年化周期 |
| 信息比率 | 超额收益均值 / 跟踪误差，年化 |
| 跟踪误差 | 逐根超额收益的标准差，年化 |
| 上涨/下跌捕获 | 基准涨/跌时策略的平均表现 ÷ 基准平均表现 |
| 超额胜率 | 逐根比较，策略跑赢基准的比例 |

结果同时存到 `metrics.benchmark` 与 `comparison`（重基到 100 的双线序列，供图表叠加）。

### 判定逻辑（有真实缺陷，已修）

第一版判定把"超额收益"用**小数**传给按**百分数**设定阈值的函数：

```python
verdict=_verdict(excess, alpha, beta, information_ratio)   # excess = -0.18
# 而阈值是 -5（代表 -5%）
```

结果 -18% 的超额被判定为"差异不显著（±5% 以内）"——完全误导。

修复为 `excess * 100, alpha * 100`，并补了两个回归测试锁定单位。

### 判定文案区分四种情况

| 情形 | 输出 |
|---|---|
| 超额 ≤ -5%，alpha > 0 | 跑输基准 X%：alpha为正但仓位暴露不足，错过大部分上涨 |
| 超额 ≤ -5%，alpha ≤ 0 | 跑输基准且alpha为负，策略未创造价值 |
| 超额 ≥ +5%，alpha > 0 且 IR > 0.3 | 跑赢基准且alpha为正，超额收益相对稳定 |
| 超额 ≥ +5%，alpha ≤ 0 | 收益高于基准但alpha为负：超额来自更高暴露，不是能力 |

## 真实数据验证

招商银行 800 根日线，sma_cross(fast=10, slow=30)：

```
策略收益  +13.99%
基准收益  +32.11%   （买入持有）
超额收益  -18.11%
Alpha      +0.46%（年化）
Beta        0.41
信息比率   -0.37
跟踪误差   15.9%
上涨捕获   43%      下跌捕获 43%
超额胜率   51%
判定：跑输基准 18.1%：alpha为正但仓位暴露不足，持有期间错过大部分上涨
```

这个诊断是准确的：策略的 beta 只有 0.41（大部分时间空仓），
所以在上涨市里必然跑输；alpha 微正说明选中的时段略优于平均，但幅度不足以弥补踏空。

## 测试（13 项）

- 满仓策略的 beta ≈ 1、相关系数 ≈ 1、超额 ≈ 0；
- 空仓策略 beta = 0、波动为 0；
- 超额收益定义（策略 − 基准）；
- 上涨/下跌捕获各 50% 的构造用例；
- 超额胜率（含"跌的时候跑赢也算赢"的语义）；
- 样本不足时返回"样本不足"而非崩溃；
- 五种判定文案；
- 重基到 100 的对齐与长度不匹配处理；
- **单位回归**：-18% 必须判为"跑输"，+11% 必须判为"跑赢"。

全量：**290 passed**。
