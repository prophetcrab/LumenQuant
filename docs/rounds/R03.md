# R03 模拟交易核心

## 需求设计
支持市价/限价、买入卖出、持仓、成交与撤单；下单前校验资金、持仓、名义金额、最小下单量与频率；任何成交必须与资金流水、持仓、订单状态在同一事务内一致。验收：市价单立即成交、限价单挂起并在价格穿越后成交、超资/超仓被拒、重复 clientOrderId 幂等。

## 代码编写
- `risk/policy.py`：`RiskLimits` + `RiskPolicy.validate`，纯函数。
- `trading/models.py`：Order、Fill、Position。
- `trading/service.py`：状态机 `new→open→filled/cancelled/rejected`，市价滑点、手续费、均价成本、已实现盈亏。
- `trading/ports.py` + `adapters.py`：现金端口与行情端口适配器，服务不导入他模块 ORM。
- `trading/engine.py`：后台撮合循环。
- 账户模块新增 `post_cash()`（事务内记账，不自行提交）。

## 代码审查
1. 新建 Position 时 `avg_price` 未显式赋值，未 flush 前为 None → 显式初始化并 flush（Bug，已修复）。
2. `post_cash` 允许负余额？买入前已校验，卖出只会增加现金，暂无风险；R12 增加权益级校验。
3. `match_open_orders` 捕获执行冲突后把订单标记 rejected，避免无限重试（设计完善）。
4. 部分成交字段已预留但 R03 只做全量成交，避免过度设计。

## 优化
- 成交与账本一次提交，撤销时回滚干净。
- 现金余额始终由账本求和，无冗余字段可漂移。
- 订单创建时预生成 ID，成交流水可直接引用。
