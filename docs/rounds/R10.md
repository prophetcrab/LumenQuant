# R10 AI 助手

## 需求设计
一个能用自然语言查询账户/持仓/订单/行情/策略/回测/自动运行的助手。关键约束：
工具只读、数字必须来自真实系统、离线可用；配置 LLM 后可由模型选择工具并组织语言。

## 代码编写
- `assistant/tools.py`：9 个只读工具（ToolBox），签名与描述可被 LLM 直接消费。
- `assistant/service.py`：
  - 本地模式：正则意图 + 标的行为 `BTC/ETH/...`、周期识别、策略别名（“双均线/海龟/布林”）。
  - LLM 模式：OpenAI 兼容 `chat/completions` + function calling，最多 4 轮，超时/失败自动降级本地。
- `assistant/router.py`：`/chat`、`/tools`、`/tools/{name}`、`/status`。
- 前端 `AssistantPage`：对话流、工具标签、快捷问题、工具清单、Enter 发送。

## 代码审查
1. 自然语言“BTC 现在什么价”未被行情意图命中 → 增补“什么价/多少钱/报价”等表达（缺陷，已修复）。
2. 工具集刻意不含任何写操作（下单/撤单/出入金），即使模型幻觉也无法移动资金 → 已由测试断言。
3. LLM 失败不能影响可用性 → 捕获异常后降级本地模式并记录日志。
4. 账户缺省时工具自动选第一个活跃账户，避免前端必须传参。

## 优化
- 本地意图匹配优先级：回测 → 信号 → 常规查询，避免“回测 MACD”被“策略列表”抢走。
- 工具结果截断到 8KB 再送回模型，控制上下文成本。

## 模块测试
7 例：工具只读性、总览数字、持仓文案、行情/策略意图、回测不产生订单、空消息、未知工具。

## 系统测试
4 例 REST：状态/工具清单、无账户问答、带账户问答与直接工具调用、参数校验。
浏览器实测：点击快捷问题返回真实持仓与浮盈，附 `list_positions` 工具标签。
