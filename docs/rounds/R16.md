# R16 数据管理

## 需求设计
研究数据必须可进可出、可体检：
- CSV 导入（毫秒时间戳、OHLC 校验、去重、可选覆盖）；
- CSV 导出（按标的与周期，带 Content-Disposition 便于下载）；
- 数据质量报告：重复时间戳、非单调、非法 OHLC、缺口；
- 覆盖清单：每个标的的起止时间与数量。

## 代码编写
- `data/service.py`：导入/导出/质量/覆盖，严格校验，分批写入，审计留痕。
- `data/router.py`：`/coverage`、`/quality`、`/export`、`/import`（multipart）。
- 前端 `DataPage`：拖拽式文件选择、写入方式、质量卡片、覆盖表与逐行导出。

## 代码审查（缺陷与修复）
1. `Form(default=...)` 处误写为不可能成立的条件表达式 → 语法级错误，已修正。
2. FastAPI 表单依赖缺失（`python-multipart` 未安装）→ 测试直接暴露，已安装并写入 requirements。
3. 导入只允许基础周期，其他周期读取时聚合，避免同一数据存在两份真相（设计约束）。
4. 时间戳不在周期边界时向下对齐，避免产生“半根”K 线。

## 测试
单元 5 例：去重、非法行跳过、覆盖+导出往返、周期/内容校验、缺口检测。
全量 `pytest`：108 passed。实测 6 个标的各 11,603 根 15m K 线，质量检查全部为 0 缺陷。
