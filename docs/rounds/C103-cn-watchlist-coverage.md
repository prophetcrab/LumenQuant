# C103：A 股盯盘页的信息覆盖

## 背景

原先的「A股标的」表格只显示代码、名称、板块、现价、涨跌、涨跌停、状态。
PE / PB / 市值 / 换手 / 振幅 / 量比 / 均线 / RSI 这些数据**上游全都有**，
只是没展示。

## 数据来源梳理

三个上游各知道一片，没有一个知道全部：

| 上游 | 提供 | 时效 |
|---|---|---|
| 腾讯实时报价 | 最新价 / 开高低 / 成交量 | 15s 轮询 |
| 新浪全市场快照 | PE / PB / 市值 / 换手 / 成交额 / 振幅所需的高低价 | 按需 + 60s 缓存 |
| 本地下游 K 线 | MA5/20/60、RSI14、5/20 日动量、量比、ATR%、距 20 日高点 | 零网络 |

## 实现

新增 `backend/app/modules/cn/watchlist.py` 的 `build_watchlist`，端点为
`GET /api/cn/data/watchlist`。

### 三级价格优先级

```
实时报价 > 新浪快照 > 本地 K 线收盘价
```

每行记录 `price_source`，所以一个看起来是实时价的值可以追溯来源。这一点很重要：
一个陈旧的价格显示成实时，是盯盘页最危险的错误。

### 一个必须绕过的限制

`ScreenerService._normalise` **刻意只保留筛选需要的字段**，`high`/`low`/`open`/
`volume` 因此不会出现在它的输出里。但盯盘需要盘中振幅。

我没有去改 screener 的契约（那是筛选服务，不该为一个它不服务的调用方扩容），
而是在 watchlist 里单独读一次原始快照：

```python
def _snapshot_ohlc(screener):
    """Raw OHLC/volume from the same snapshot, keyed by code."""
```

**这个坑是实测发现的**：第一版直接用 `snap.get("high")`，结果振幅列全是 `—`。

### 不可得的字段显式声明

任何上游都不提供的字段，返回结构里带原因，而不是渲染成空列：

```json
"coverage": {
  "industry":  { "available": false, "detail": "当前行情快照不含行业分类；需要额外接口，暂未接入" },
  "fund_flow": { "available": false, "detail": "需要主力资金流接口，暂未接入" },
  "financials":{ "available": false, "detail": "季频财报，需要额外接口；8 年也只有 32 个季度，因子研究价值有限" }
}
```

**空单元格会被读成"零"或"没算"**，而"上游不提供"是事实。页面右侧「信息覆盖」
卡片把这六个分组逐个列出来，已接入的标绿。

### 快照失败不影响价格

新浪接口会间歇性失败（实测一次丢了 14 页）。这时：

- 价格退回到 K 线收盘价，`price_source="candle"`
- 估值列留空（`pe: null`）
- `warnings` 说明原因
- 页面照常渲染

不能让"估值数据没了"变成"整页空白"。

## 关于因子挖掘的一个判断

这些字段现在能看了，但**不建议立刻用来挖因子**。理由是样本宽度：

| 标的数 | 交易日 | 总观测 | 可识别 IC 精度 |
|---|---|---|---|
| **9（当前）** | 1500 | 13,500 | **0.026** |
| 300 | 1500 | 450,000 | 0.010 |
| 500 | 1500 | 750,000 | 0.008 |

A 股因子的真实 IC 通常只有 0.01–0.03。9 只标的的横截面里，因子信号和噪声同量级——
试 2–3 个因子就会过拟合。

**好消息是基础设施不是障碍**，实测：

- 新浪全市场接口可拿 **5,576 只**标的
- 单标的 8 年日线 **312ms/只**
- 全市场日线导入 **约 28 分钟**（单线程）
- 存储量约 1,080 万行，SQLite 完全能扛

所以下次要挖因子，第一步是把标的池从 9 扩到 500+，而不是引入更多信息类型。

## 验证

`tests/unit/test_cn_watchlist.py`（5 项）：

| 用例 | 断言 |
|---|---|
| 三源合并 | 价格/估值/技术面同时到位，MA60 在只有 40 根时不伪造 |
| 实时价优先 | `price_source="realtime"`，年龄与新鲜度透传 |
| 不可得字段有原因 | industry/fund_flow/financials 三项 `available=false` 且 `detail` 非空 |
| 快照失败仍出价格 | 价格退回 K 线、PE 为空、有警告 |
| 缺历史时警告 | 无 K 线的标的 `technicals=null`，`warnings` 说明 |

快照失败不捕获——各自对应测试变红。
