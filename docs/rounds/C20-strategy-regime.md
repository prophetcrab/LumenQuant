# 迭代记录 C20：真实数据暴露的策略缺陷

## 背景

C17–C19 打通真实数据后，用 800 根真实日线（约 3 年）重跑策略矩阵，
结果与合成数据完全不同：

| 策略 | 800 根真实日线（茅台） |
|---|---|
| buy_and_hold | -19.69%（基准） |
| sma_cross | **-42.54%** |
| ema_trend | **-28.44%**（胜率 4.2%） |
| macd_momentum | -24.09% |
| atr_channel | -23.79% |
| donchian_breakout | -17.23% |
| rsi_reversion | +5.16% |
| bollinger_reversion | +10.03% |
| stochastic_reversal | +26.19% |

趋势类全线大亏，均值回归类盈利。这个分布本身是**合理的**：
茅台这三年是下跌市（买入持有 -19.7%），趋势跟踪在震荡下跌中最容易连续止损。

但 `ema_trend` 胜率 4.2%（24 笔仅 1 笔盈利）明显异常，需要单独排查。

## 定位

逐笔看交易：

```
2023-09-18 -> 2023-09-21  1822 -> 1806  -1.01%
2023-11-01 -> 2023-11-13  1795 -> 1764  -1.83%
2023-11-15 -> 2023-11-16  1774 -> 1752  -1.34%
2023-11-21 -> 2023-11-27  1783 -> 1761  -1.35%
```

全部是"小亏离场"，持仓 2–12 天。结合信号逻辑：

```
buy 条件 = 价格上穿 EMA  且 ADX ≥ 20
       或 价格在 EMA 上方 且 ADX 升破 20 且 EMA 上升
```

问题：**ADX 只衡量趋势强度，不衡量方向**。下跌趋势中 ADX 同样会走高，
于是策略在每一次下跌反弹里买入，然后被下一次下跌打止损。

第一次修复（加 EMA 上升条件）几乎没效果——下跌趋势中的 EMA 也会短期翘头。

## 修复：牛熊状态过滤

趋势跟踪策略的前提是"市场处于上升趋势"。新增两个参数：

| 参数 | 默认 | 作用 |
|---|---|---|
| `regime_period` | 200 | 长期均线（约一年） |
| `require_regime` | `true` | 只在价格位于长期均线上方时做多 |

修复效果（同样 800 根数据）：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 交易数 | 24 | 4 |
| 收益 | -28.44% | **-6.76%** |
| 胜率 | 4.2% | 25.0% |
| 最大回撤 | 28.60% | **8.57%** |

平安银行同样改善（-11.56% → -6.22%，回撤 15.80% → 14.43%）。

亏损没有变成盈利——因为这段行情本来就是下跌市，**做多趋势策略在熊市
亏钱是正确行为**，过滤的价值在于把亏损从"反复抄底"收敛到"少数几次尝试"。

## 新增测试（2 项）

1. `test_ema_trend_regime_filter_avoids_bear_market_entries`
   - 开启过滤后的买点数不得多于关闭时；
   - 下跌段的每一次买入都必须发生在长期均线上方。
2. `test_ema_trend_regime_is_configurable`
   - 默认开启，周期 200，可显式关闭用于对比研究。

## 报告方式修正

C17 的报告只看了 120 根数据，得出"收益 +66%~+78%"的结论。
那是短周期恰好处于上涨段的结果，**不具代表性**。

本轮开始，凡涉及策略表现的结论都基于 800 根（约 3 年）数据，
并同时给出买入持有基准，避免把 β 当成 α。

## 教训

合成数据可以验证"链路是否通"，但**不能验证策略是否有效**。
真实数据第一次接入就暴露了一个在合成数据上"看起来正常"的策略缺陷，
原因是合成生成器的趋势段太规整、缺少真实的下跌反弹结构。

因此策略结论必须以真实、足够长的数据为准，并且必须对照基准。
