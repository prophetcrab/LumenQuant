# R05 回测引擎与绩效指标

## 需求设计
事件驱动回测，严格遵守「收盘信号、下一根开盘成交」；含手续费与滑点、可选止损止盈；输出权益曲线、逐笔交易与 18 项绩效指标；结果持久化，可列表/回放/删除。验收：全部 9 个策略可回测、权益曲线长度等于 K 线数、费用与盈亏守恒、无交易时不崩溃。

## 代码编写
- `engine.py`：单仓位多头回测；成交在下一根开盘；跳空时止损按更差的开盘价成交。
- `metrics.py`：总收益、CAGR、最大回撤及持续期、年化波动、Sharpe、Sortino、Calmar、胜率、盈亏比、平均/最佳/最差交易、持仓时长、暴露度。
- `service.py`：参数校验、买入持有基准对比、结果落库。
- `models.py`：`backtest_runs` 表。

## 代码审查
1. 仓位数量直接用 `round`，可能因浮点进位超过现金而永不成交 → 改为向下取整到 1e-8（Bug，已修复）。
2. 仓位预算未计手续费，100% 仓位时必然资金不足 → 分母加入费率（Bug，已修复）。
3. 无交易时盈亏比返回 0 会误导 → 改为 `null`，前端显示“—”（语义缺陷，已修复）。
4. 跳空穿过止损时按开盘价成交，比止损价更保守，符合真实撮合。

## 优化
- 指标预处理一次，回测循环只做数组访问；3000 根 K 线单策略回测 < 20ms。
- 权益点结构与前端 ECharts 直接对齐，无需二次转换。
