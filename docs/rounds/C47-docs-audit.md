### 2. 验收清单缺整个 C 轮

原来的清单只覆盖 R01–R20 与 A 股接入，C24–C46 的二十多项能力完全没有条目：
组合分析、参数交接、风险中心、实盘自动开关、数据删除……

补了一节"持续迭代阶段（C24–C47）"，用主题表格列出每轮的交付内容，
并指向 `docs/rounds/` 的完整记录。

### 3. 代码报告里的"已知债务"已解决

写着：

> 前端无自动化测试 | 回归靠人工 | 加 Playwright 冒烟用例

C35 已经用 Vitest 解决（48 项），只是实现方式不是 Playwright——
因为要钉住的是组件状态与类型问题，不是真实渲染。更新为"已解决"并注明实际方案。

缺陷表也只到 R19。补上 C 轮发现的 31 项缺陷，其中 4 项标为**安全**：

- C39 实盘自动运行绕过确认头
- C39 关闭开关后已存在实盘实例仍下单
- C43 归档账户后实例仍在交易

### 4. 安全清单不完整

原来只写"三重条件"。C39 之后实际是四重（自动运行有独立开关），
且增加了若干执行时复查。重写为完整的六条，并明确记录一条**刻意的例外**：

> 关闭自动开关不影响止损等保护性离场（避免"关掉保护"的反向风险）

### 5. `quickstart.md` 的测试命令失效

```powershell
..\.venv\Scripts\python.exe -m pytest tests/stress -q # 压测（需先启动服务）
```

这条命令从来就跑不通：`tests/stress` 里的脚本需要参数（账户 ID、并发数），
有的是进程内脚本不需要服务。改为指向 `tests/stress/README.md`。

同时补上前端测试命令（原来完全没有）与"362 项 / 48 项"的真实数字。

### 6. `.env.example` 缺新开关

`LQ_LIVE_AUTO_TRADING_ENABLED` 在 C39 引入，但示例环境文件里没有。
使用者照着 `.env.example` 配置，永远开不了实盘自动交易——
而且不会有任何提示，只会遇到 403。

## 修改过程中踩到的坑

用脚本批量替换文档时，PowerShell 风格的路径 `D:\LumenQuant\frontend`
里的 `\f` 和 `\t` 被 Python 当成转义序列，写进了文件：

```
cd D:\LumenQuant
rontend
```

`\f` 是换页符，`\t` 是制表符——文件内容被静默破坏。
发现后从 git 恢复，改用 `Edit` 工具逐块替换。

**教训**：文档里的 Windows 路径必须用 `Edit` 精确修改，
不能用 Python 字符串拼接批量处理。
