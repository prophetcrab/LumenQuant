# R06–R08 前端基座、行情、交易、策略、回测、账户与组合

## 需求设计
面向 2560×1440 的浅色高密度工作台。信息层级：侧栏导航 → 顶部账户切换 → 卡片网格。
要求：行情多周期 K 线 + 指标叠加；下单、持仓、挂单、成交闭环；策略参数动态表单与信号预览；
回测配置、权益曲线、18 项指标、逐笔交易与历史；账户出入金与账本；组合权益、回撤、配置构成。

## 代码编写
- 设计系统：CSS 变量（中性灰底、靛蓝强调、低饱和涨跌色）、卡片/表格/表单/徽章/骨架/弹窗。
- `shared/api.ts`：类型化 API 客户端与统一错误解析。
- `AccountProvider`：账户选择持久化到 localStorage；`useAccount` 全站共享。
- 页面：总览、行情、交易、策略库、回测、组合、账户、AI 助手占位。
- 图表：K 线 + 成交量 + 可叠加均线；权益面积图与配置环图。

## 代码审查（真实缺陷与修复）
1. 叠加线使用 `[time, value]` 配 category 轴被 ECharts 忽略 → 改标量数组（已修复）。
2. RSI/MACD 等振荡指标被画进价格坐标轴，压缩价格并出现 0 线 → 只允许价格量纲序列叠加（已修复）。
3. 信号图缓存键缺少序列长度，400 根 K 线与 800 点叠加错位 → 缓存键加入长度（已修复）。
4. `avg_hold_bars` 把毫秒差当 K 线数（显示 7920 万）→ 按周期换算并补测试（已修复）。
5. 入金推高权益被误算为“累计收益” → 新增 `net_contributions`，收益率按净投入计算（已修复）。
6. TypeScript 7 移除 `baseUrl` → paths 改相对路径（构建修复）。

## 优化
- TanStack Query 统一轮询节奏：权益 4s、持仓 5s、行情 6s、快照 5s，避免瀑布请求。
- 图表 `notMerge` + 固定高度，切换标的无布局跳动。
- 数字统一 tabular-nums，表格对齐稳定。
