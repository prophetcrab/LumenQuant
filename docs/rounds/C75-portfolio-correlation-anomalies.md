# 迭代记录 C75：相关性矩阵的异常跳变检查

## 动机

C73 给单条回测曲线和合并曲线都加了"单根权益变动超出合理范围"的检测，
但 C73 的文档留下了这条：

> 相关性分析也应当警惕：两条曲线如果都含异常跳变，相关性会被严重扭曲。
> 目前没有自动检查。

这个洞比看上去更危险。相关性是"要不要把这两个策略放在一个组合里"的唯一依据，
而 Pearson 相关系数对离群值极其敏感：**一根 −95% 或 +80% 的 bar 就能主导整个协方差**。
用户会看到一张干净的相关性热力图，据此判断分散效果——而那个数字其实来自一个账务错误。

## 实测扭曲幅度

用注入异常的方式量化（`+1.75×` 于一条 sleeve 的中点之后）：

| | ETH ↔ SOL 相关性 |
|---|---|
| 原始（无异常） | 0.0058 |
| 含 1 根 +73% 跳变 | **0.2302** |
| 剔除该 bar 后重算 | **0.0317** |

一根 bar 把相关性放大了 40 倍，足以让一对真正独立的策略看起来"中等相关"，
反之（−95% 塌陷）也会把本该高度相关的两者压成"看起来能分散"。

## 实现

### 1. 定位到具体 sleeve 与时间点

复用 `engine.IMPLAUSIBLE_BAR_RETURN`（50%）作为阈值——与单条回测、多标的合并曲线
完全一致，一条曲线在别处会告警，不可能在这里溜过去。

新增 `_indexed_returns`：`_returns` 会在基数为非正时丢项，导致索引错位，
无法说清异常来自哪一根。这个变体保留 bar 索引，告警因此能给出精确时间戳。

### 2. 剔除后重算

对每对 sleeve，把**所有**出现异常的 bar 索引从双方同时剔除，保证逐点对齐。
这样得到一张"稳健矩阵"。

### 3. 分级输出

| 情况 | 输出 |
|---|---|
| 无异常 | 只有原始矩阵，无额外噪音 |
| 有异常 | 原始矩阵 + `correlation.robust`（矩阵、剔除根数、样本数） |
| 任一配对变化 ≥ 0.15 | 追加"相关性被显著扭曲"的具体前后值 |

阈值门控只用于**告警文案**，不用于是否提供矩阵：原始矩阵此时已知不可信，
用户必须有一个可比对的参照物。

### 4. 前端

相关性卡片在原矩阵下方追加稳健矩阵，并注明剔除根数与样本量。
副标题同步改为"原始矩阵含异常跳变，下方另给剔除后的结果"。

## 实现过程中发现并修复的一个 bug

第一版把矩阵算出来了，但返回语句仍是：

```python
"correlation": {"labels": labels, "matrix": matrix},   # 旧字面量
```

结果是**告警说"已剔除异常 bar 重算相关性"，接口里却没有那张矩阵**。
用户会照着文案去找一个不存在的数据，而且没有任何报错。

测试断言 `robust is not None` 直接抓住了它。这条断言保留在测试里，
注释说明它针对的就是这个回归。

## 验证

新增 3 个集成测试：

| 用例 | 断言 |
|---|---|
| 异常 sleeve 被告警 | 告警包含 sleeve 名称、跳变幅度、时间戳、"不可直接采信" |
| 稳健矩阵随异常一起返回 | `dropped_bars ≥ 1`、矩阵形状一致、样本数少于原始 |
| 干净曲线不产生噪音 | 无 `robust` 字段、无"异常跳变"告警 |

真实数据（三标的、250 根小时线）实测：

```
CLEAN  corr  ETH↔SOL 0.0058, robust absent, warnings []
DIRTY  corr  ETH↔SOL 0.2302
ROBUST corr  ETH↔SOL 0.0317, dropped 1, 剩 198 个样本
WARN   rsi_reversion · ETHUSDT 的权益曲线有 1 根异常跳变（最大 +73.3%，位于 2026-10-17 21:00）
WARN   已剔除 1 根异常 bar 重算相关性（剩 198 个样本）
WARN   相关性被异常跳变显著扭曲：第 2 与第 3 条曲线的相关性从 0.23 变为 0.03（变化 -0.20）
```

回归：后端 **461 passed**（新增 3 项），前端 66 passed，`tsc` 与构建干净。

## 已知限制

1. **只检测单根跳变**：连续多根、幅度均低于 50% 的缓慢漂移不会触发。
2. **不做稳健统计替换**：剔除是唯一手段，没有用中位数/MAD 重估。
3. **样本下限**：剔除后不足 49 个样本就不输出稳健矩阵——那已不足以支撑相关性结论，
   此时只保留"曲线有问题"的告警。
