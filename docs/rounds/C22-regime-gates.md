# 迭代记录 C22：把牛熊过滤推广到其他趋势策略

## 方法（先量化，再改）

不凭直觉给所有策略加过滤，而是先用真实数据测出**每个策略开启/关闭过滤的差异**：

同一份 800 根真实日线，对比"原始序列"与"仅保留价格在 200 日均线上方的区间"：

| 策略 | 招商银行 原始 | 招商银行 过滤 | 结论 |
|---|---|---|---|
| sma_cross | +12.13% | **+35.64%** | 显著改善 |
| donchian_breakout | +7.66% | **+21.98%** | 显著改善 |
| macd_momentum | +27.33% | +11.12% | **变差** |
| atr_channel | +12.17% | +7.69% | **变差** |

结论：**不能一刀切**。只给收益改善明确的两个策略加过滤，其余保持原样。

## 改动

| 策略 | `require_regime` 默认 | `regime_period` |
|---|---|---|
| `ema_trend` | **true**（C20 已定，胜率 4%→25%） |
| `sma_cross` | false | 200 |
| `donchian_breakout` | false | 200 |
| `macd_momentum` / `atr_channel` | 不提供 | — |

为什么 sma_cross 与 donchian 默认关闭：开启后需要约一年数据暖机，
在短序列（100–200 根）上会直接报"数据不足"。默认关闭保证开箱可用，
用户研究长期策略时可显式打开。

## 顺带修复：暖机不足的提示

原来只报 `not enough data: 121 bars available, 203 required`，
用户不知道是哪参数导致的。

现在会说明原因与解法：

```
数据不足：仅有 121 根 K 线，需要至少 203 根。
（该策略启用了牛熊过滤（200 日均线），可增大 K 线数量、或设置 require_regime=false 关闭过滤）
```

## 教训

**参数默认值决定了产品的开箱体验。**
把"正确但需要一年数据"的过滤器设为默认，会让短序列直接不可用——
这在测试里表现为 7 个用例同时失败，是个好信号：默认值应当服务于最常见的用法。
