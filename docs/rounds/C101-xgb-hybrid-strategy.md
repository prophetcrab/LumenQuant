# XGBoost 混合策略：实现与回测报告

> 结论先行：**策略实现正确、无前视偏差，但在真实成本下不赚钱。**
> 报告如实呈现这一点，并给出证据说明原因。请勿据此用真金白银运行。

## 1. 实现

新增策略 `xgb_hybrid`（`backend/app/modules/strategies/library/ml.py`），三层结构：

| 层 | 作用 | 参数 |
|---|---|---|
| XGBoost 方向概率 | 预测未来 4 根 K 线涨幅是否超过阈值 | `n_estimators=200, max_depth=4, lr=0.05` |
| 趋势过滤 | 价格低于 EMA200 时否决买入 | `require_regime, regime_period=200` |
| 波动率门控 | ATR% 过高时空仓 | `max_atr_pct=6.0` |
| 最短持有 | 入场后 N 根内不响应离场 | `min_hold_bars` |

26 个特征，全部因果（t 时刻只用 ≤t 的数据）：

- 动量：1/3/6/12/24 根收益率
- 波动：24 根滚动标准差、波动率比值（24 根 / 96 根）
- 位置：RSI14、ADX14、MACD 柱、布林 %B 与带宽、距 EMA20/50/200 的偏离
- 微观结构：实体占幅、上下影线占比、成交量 z-score
- 周期：小时与星期的正弦/余弦编码

### 无前视偏差的保证

训练严格走前向验证，每个区块只用**标签已完全实现**的样本，并在训练/测试之间留出
`horizon` 根隔离带（标签依赖 `close[i+horizon]`，不留隔离带就会泄漏）：

```
for 每个区块:
    训练集 = [warmup, 区块起点 - horizon) 中特征完整且标签已知的样本
    预测该区块
```

**验证方法**：把 6000 根序列截断到 4500 根重新 `prepare`，前 4500 根的预测概率与
完整序列**逐位完全一致**（`abs(diff) < 1e-9`）。这是无前视的直接证据——如果模型
偷看了未来，截断后历史部分的预测必然改变。

## 4. 为什么亏：诊断证据

### 4.1 模型在预测波动，不是方向

| 相关性 | 数值 |
|---|---|
| IC（预测概率 vs **带符号**未来收益） | **+0.0008** |
| IC（预测概率 vs **绝对**未来收益） | **+0.2586** |

预测概率与"涨跌方向"几乎零相关，与"波动大小"相关 0.26。

按预测概率分位看未来收益：

| 概率分位 | 样本数 | 未来均值 | 上涨占比 |
|---|---|---|---|
| 最低 10% | 1600 | -0.3 bp | 51.3% |
| 最高 10% | 1600 | -1.9 bp | 50.3% |
| **两者之差** | | **+1.6 bp** | |

最高和最低概率组的收益几乎没有差异——模型没有区分能力。

### 4.2 逐折 IC 符号乱跳

| 折 | 训练样本 | 样本外 IC |
|---|---|---|
| 0 | 3,776 | +0.058 |
| 1 | 4,776 | +0.073 |
| 2 | 5,776 | +0.083 |
| 3 | 6,776 | +0.070 |
| 4 | 7,776 | -0.009 |
| 5 | 8,776 | -0.004 |
| 6 | 9,776 | **-0.072** |
| 7 | 10,776 | **-0.102** |
| 8 | 11,776 | +0.013 |
| 9 | 12,776 | -0.056 |
| 10 | 13,776 | +0.053 |
| 11 | 14,776 | +0.036 |
| 12 | 15,776 | -0.062 |
| 13 | 16,776 | +0.063 |
| 14 | 17,776 | -0.021 |
| 15 | 18,776 | -0.001 |

如果模型捕捉到稳定规律，IC 应该同号且量级稳定。这里在 +0.08 到 -0.10 之间随机
摆动，是噪声的典型形态。分年度看同样翻转：2024 年 +0.19（仅 99 个样本）、
2025 年 +0.016、2026 年 -0.028。

### 4.3 成本吃掉一切

| 成本假设 | 总收益 | 交易数 |
|---|---|---|
| 真实成本 10bp + 3bp | -2.66% | 11 |
| 半成本 5bp + 1bp | -1.22% | 11 |
| 近零成本 2bp + 0bp | -0.39% | 11 |
| **零成本** | **+0.03%** | 11 |

**即使零成本，收益也只有 +0.03%。** 这说明问题不在成本——策略本身没有 alpha，
成本只是把接近零的结果压成负数。

成本门槛的算术：往返 26bp。实测最高概率组的超额优势只有 +13.3bp（持有 4 根）。
13.3 - 26 = **-12.7bp 每笔**，结构上必亏。

### 4.4 24 组参数全部亏损

扫描 `horizon ∈ {4,12,24}` × `min_hold ∈ {0,12,24,48}` × `entry_prob ∈ {0.58,0.65}`：

**正收益组合数：0 / 24。**

最好的一组是 `H=4, min_hold=0, entry=0.65` 的 -2.66%。

## 5. 顺带修掉的两个真实缺陷

### 5.1 `MarketService.candles` 静默截断到 5000 根

回测层接受 `bars <= 20_000`，但行情层硬上限 5,000。请求 20,000 根实际只拿到
4,999 根——静默截断，不报错。ML 策略需要长训练窗口，几乎无法使用。

现在 `MAX_CANDLE_LIMIT = 20_000`，聚合临时集上限提升到 100,000 根，两层契约一致。

### 5.2 契约测试的 fixture 太短

`test_strategy_can_eventually_signal` 用 400 根样本，而 ML 策略暖机需 4,217 根，
测试报"从未产生信号"。改为按策略 `warmup()` 自适应长度——测试意图是"能产生信号"，
不是"400 根内能产生信号"。

## 7. 这个策略的正确用法

**它是一个可运行的方法实现与评估流程，不是一个盈利策略。**

拥有真实价值的三个部分：

1. **走前向验证的骨架**：`_walk_forward_probabilities` 的隔离带逻辑可以复用到任何
   监督学习策略。直接训练全序列再回测会得到天文数字的假收益，这套代码避免了这个陷阱。
2. **特征工程**：26 个因果特征，可直接用于其他模型（LightGBM、神经网络）。
3. **评估方法论**：本报告演示了如何诚实地判定"策略无效"——看逐折 IC 是否稳定、
   看 IC 是对方向还是对波动、做成本敏感性分析、扫描参数确认不是调参不当。

## 8. 如果想让 ML 真正有用

基于本次诊断，几个方向：

1. **用波动预测做仓位管理，而不是方向择时**。IC 对绝对波动是 0.26，这是真实信号。
   但需要配合一个本身有边际的底仓策略——在纯下跌样本里，降波动只是少亏。
2. **换预测目标**：预测"未来 N 根内是否触及 +X% 且未触及 -Y%"（三重障碍法），
   比预测带符号收益更贴近交易的收益结构。
3. **降频**：1h 上 26bp 成本的占比太高（4 根持有期波动仅 96bp）。日线或周线频率
   下成本占波动比例降到 10% 以下，但需要相应更长的历史（日线只有 999 根，
   训练样本太少）。
4. **换标的**：BTC 是流动性最好、被研究最充分的品种，也最难有持续 alpha。
   市值更小、覆盖更少的品种通常有更多定价无效。
