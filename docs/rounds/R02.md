# R02 行情引擎与指标库

## 需求设计
提供可离线自演进的行情底座：标的目录、多周期 K 线、实时快照、8 类技术指标；数据在重启后可复现，且不依赖外网。验收：6 个标的自动入库、15m 起 aggregation 到 1d 正确、指标长度对齐且暖机段为 null、非法周期/指标返回 422。

## 代码编写
- `feed.py`：确定性合成行情（哈希种子 + 6h 趋势状态 + 偶发跳变）、模拟时钟（默认 60 倍速）、时间周期工具。
- `aggregate.py`：纯函数 OHLCV 聚合，开高低收量严格由子周期推导。
- `indicators.py`：SMA/EMA/RSI/MACD/BOLL/ATR/STOCH/ADX，缺失值统一 `None`。
- `engine.py`：后台模拟器，维护 live bar、补齐历史、批量落库。
- `service.py` + `router.py`：读取服务与 REST。

## 代码审查
1. `Candle.id` 使用 `BigInteger` 在 SQLite 下不自增 → 改 `Integer` 走 rowid 别名（Bug，已修复）。
2. ADX 平滑窗口存在差一错误与越界写 → 重写为显式 DX 序列 + Wilder 平滑（Bug，已修复）。
3. `MarketService.candles` 中 live bar 分支重复 → R14 清理，行为正确故暂留。
4. 模拟时钟与已落库历史可能倒挂 → 新增 `ensure_at_least` 校准起点（设计缺陷，已修复）。

## 优化
- 历史落库按 2000 行分批 `executemany`，6 标的最慢约 1.3s。
- 指标全部为纯函数、无 I/O，便于回测复用与单元测试。
- 聚合按 15m 边界对齐，避免跨周期漂移。
