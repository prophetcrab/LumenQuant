# 真实 A 股行情接入

## 两种模式

| 模式 | 配置 | 数据来源 | 是否需要网络 |
|---|---|---|---|
| 合成（默认） | `LQ_CN_DATA_SOURCE=synthetic` | 本地确定性生成器 | 否 |
| 真实 | `LQ_CN_DATA_SOURCE=tencent` | 腾讯公开行情接口 | 是 |

默认合成模式，保证离线可跑、结果可复现。真实模式需显式开启。

## 配置

```env
LQ_CN_DATA_SOURCE=tencent
# 启动时自动同步（失败只记日志，保留本地数据）
LQ_CN_SYNC_ON_START=true
LQ_CN_SYNC_DAILY_LIMIT=800
LQ_CN_SYNC_INTRADAY_LIMIT=320
```

## 接口

```bash
# 数据源健康（含延迟）
curl http://127.0.0.1:8000/api/cn/data/source | jq

# 同步全部 A 股标的
curl -X POST http://127.0.0.1:8000/api/cn/data/sync | jq

# 只同步指定标的
curl -X POST "http://127.0.0.1:8000/api/cn/data/sync?codes=600519.SH,000001.SZ" | jq

# 查看每个标的的日线滞后期
curl http://127.0.0.1:8000/api/cn/data/staleness | jq
```

前端在「A股」页有对应的数据源卡片与同步按钮。

## 数据语义

### 同步即替换

一次成功的同步会**删除该标的原有 K 线**再写入真实数据。
原因：合成行情与真实行情的价格水平完全不同（同一代码可能差 20%+），
混在一起会让涨幅与涨跌停区间失真。

若你导入过自定义 CSV，同步会覆盖它。需要保留请先用 `/api/data/export` 备份。

### 昨收优先级

涨跌停计算使用的昨收按以下优先级取：

1. 实时行情返回的昨收（最准确，反映当日盘前调整）；
2. 最新日线收盘；
3. 数据库中已有的值。

### 复权：全系统统一使用不复权价

日线接口使用**不复权**（unadjusted）数据，与实时报价同口径。

这是必须的，不是可选偏好：

1. 实时行情只能提供不复权价；
2. 交易所的涨跌停以不复权价为基准计算；
3. 若历史用前复权、报价用不复权，同一标的会出现两个价格体系——
   实测中曾导致 +192% 的虚假涨幅，且所有标的被误判为涨跌停。

因此：

- **交易与风控**用不复权价，正确性由交易所口径保证；
- **长期收益分析**若需复权，应单独导入复权序列（`/api/data/import`），
  不要与实时链路混用；
- 跨除权日的盈亏归因需人工核对，系统不做自动复权调整。

## 已知限制

1. **接口非官方**：腾讯行情是公开但未承诺 SLA 的接口，可能变更或限流。
   实现带 3 次指数退避重试（含抖动），4xx 不重试。
2. **无实时推送**：本地是"同步 + 轮询"，不是 WebSocket 推送。
   分钟线延迟取决于调用同步的频率。
3. **不含集合竞价与逐笔**：只有 OHLCV 聚合数据。
4. **仅 A 股**：加密市场仍走本地合成引擎。
