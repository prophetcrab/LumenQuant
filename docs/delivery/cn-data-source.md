# 真实 A 股行情接入

## 两种模式

| 模式 | 配置 | 数据来源 | 是否需要网络 |
|---|---|---|---|
| 合成（默认） | `LQ_CN_DATA_SOURCE=synthetic` | 本地确定性生成器 | 否 |
| 真实 | `LQ_CN_DATA_SOURCE=tencent` | 腾讯公开行情接口 | 是 |

默认合成模式，保证离线可跑、结果可复现。真实模式需显式开启。

真实模式下**合成引擎不再运行**：它只会登记 A 股标的目录，价格由实时轮询引擎
接管。两个写入方同时写同一批 bar 会让价格水平来回跳（合成 ~1695 / 真实 ~1331），
涨跌停和涨幅随之失真。

## 配置

```env
LQ_CN_DATA_SOURCE=tencent
# 启动时自动同步历史（失败只记日志，保留本地数据）
LQ_CN_SYNC_ON_START=true
LQ_CN_SYNC_DAILY_LIMIT=800
LQ_CN_SYNC_INTRADAY_LIMIT=320
# 实时报价轮询
LQ_CN_REALTIME_ENABLED=true
LQ_CN_QUOTE_POLL_SECONDS=15
```

## 接口

```bash
# 数据源健康（含模式、轮询间隔、最近一次延迟）
curl http://127.0.0.1:8000/api/cn/data/source | jq

# 所有标的的实时报价与新鲜度
curl http://127.0.0.1:8000/api/cn/data/quotes | jq

# 立即拉取一次（不等待下一个轮询周期）
curl -X POST http://127.0.0.1:8000/api/cn/data/poll | jq

# 同步历史数据（会替换该标的的原有 K 线）
curl -X POST http://127.0.0.1:8000/api/cn/data/sync | jq

# 只同步指定标的
curl -X POST "http://127.0.0.1:8000/api/cn/data/sync?codes=600519.SH,000001.SZ" | jq

# 查看每个标的的日线滞后期
curl http://127.0.0.1:8000/api/cn/data/staleness | jq
```

前端在「A股」页有数据源卡片、实时价、行情延迟列与刷新按钮。


## 数据语义

### 同步即替换

一次成功的同步会**删除该标的原有 K 线**再写入真实数据。
原因：合成行情与真实行情的价格水平完全不同（同一代码可能差 20%+），
混在一起会让涨幅与涨跌停区间失真。

若你导入过自定义 CSV，同步会覆盖它。需要保留请先用 `/api/data/export` 备份。

### 昨收优先级

涨跌停计算使用的昨收按以下优先级取：

1. 实时行情返回的昨收（最准确，反映当日盘前调整）；
2. 最新日线收盘；
3. 数据库中已有的值。

### 复权：全系统统一使用不复权价

日线接口使用**不复权**（unadjusted）数据，与实时报价同口径。

这是必须的，不是可选偏好：

1. 实时行情只能提供不复权价；
2. 交易所的涨跌停以不复权价为基准计算；
3. 若历史用前复权、报价用不复权，同一标的会出现两个价格体系——
   实测中曾导致 +192% 的虚假涨幅，且所有标的被误判为涨跌停。

因此：

- **交易与风控**用不复权价，正确性由交易所口径保证；
- **长期收益分析**若需复权，应单独导入复权序列（`/api/data/import`），
  不要与实时链路混用；
- 跨除权日的盈亏归因需人工核对，系统不做自动复权调整。

## 实时行情

### 轮询节奏

| 状态 | 间隔 |
|---|---|
| 盘中 | `LQ_CN_QUOTE_POLL_SECONDS`（默认 15s） |
| 休市 | `max(60s, 4 × 轮询间隔)` |

一次请求取全部标的（每 60 只一组），而不是逐只请求。

### 新鲜度

报价超过 `max(30s, 4 × 轮询间隔)` 判为不新鲜：

- 快照回落到数据库里的最后一根 bar；
- `/api/cn/data/quotes` 中该行 `fresh=false`；
- 前端「行情延迟」列显示橙色「滞留 Ns」。

休市时阈值放宽到 `8 × 轮询间隔`（价格本来不动）。

### 15 分钟线怎么来的

上游只提供当日 OHLC 与累计成交量，没有分时。系统按报价时间戳对齐到 15m 桶，
用连续采样重建 high/low/收盘，成交量取累计值的差分；跨桶时把上一桶写入数据库
并滚动更新当日日线。

日线只由**已收盘**的 15m bar 聚合，因此日线收盘价最多比实时价晚 15 分钟——
这是刻意的：日线供回测与指标使用，混入未收盘数据会让回测结果随查询时刻变化。

## 已知限制

1. **接口非官方**：腾讯行情是公开但未承诺 SLA 的接口，可能变更或限流。
   实现带 3 次指数退避重试（含抖动），4xx 不重试。
2. **是轮询，不是推送**：延迟上限是一个轮询间隔。腾讯接口没有 WebSocket 通道。
3. **15m 线是重建的**：只反映被采样的价格路径，真实极值可能被漏掉。适合展示与
   分钟级指标，不适合作为成交回溯依据。
4. **盘中启动时首根 bar 的开盘价**取首个观测价，而非当日开盘价。
5. **不含集合竞价与逐笔**：只有 OHLCV 聚合数据。
6. **仅 A 股**：加密市场仍走本地合成引擎。
7. **单进程状态**：多实例部署时各自轮询；数据库层靠唯一索引去重不会重复写入，
   但健康状态不共享。
