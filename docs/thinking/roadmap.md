# 20 轮路线图

每轮固定产出：需求增量 → 编码 → 代码审查 → 优化 → 模块测试 → 系统测试 → 压力测试 → 缺陷修复 → 轮次报告。

| 轮次 | 主题 | 关键交付 |
|---|---|---|
| R01 | 工程基座与账户 | 配置/DB/事件总线/审计/账户账本/测试 |
| R02 | 行情与指标 | 合成行情、K 线聚合、8 类指标 |
| R03 | 模拟交易核心 | 订单状态机、撮合、持仓、资金一致性 |
| R04 | 策略框架 | 插件注册表、8 个经典策略、动态参数 |
| R05 | 回测引擎 | 事件驱动回测、绩效指标、结果持久化 |
| R06 | 前端基座与看板 | 2K 布局、仪表盘、权益曲线 |
| R07 | 行情与交易界面 | K 线、下单面板、持仓/挂单 |
| R08 | 策略与回测界面 | 动态参数表单、回测结果可视化、账户页 |
| R09 | 策略运行时 | 后台调度、自动交易、实例启停 |
| R10 | AI 助手 | 工具调用、组合/策略问答、可选 LLM |
| R11 | 实盘接入 | Binance 适配器、密钥校验、双重开关 |
| R12 | 风控升级 | 限额、日损失、熔断、强平检查 |
| R13 | 组合分析 | 快照、回撤、归因、敞口 |
| R14 | 性能优化 | 查询索引、缓存、批量写入、回测提速 |
| R15 | 可观测性 | 请求 ID、结构化日志、审计查询、指标端点 |
| R16 | 数据管理 | CSV 导入导出、标的管理、数据质量检查 |
| R17 | 视觉打磨 | 2K 细节、空态/骨架屏、交互一致性 |
| R18 | 安全加固 | 本地令牌、限流、CORS、实盘确认头 |
| R19 | 稳定化 | 压力测试、缺陷修复、故障注入 |
| R20 | 验收交付 | 全链路系统测试、文档定稿、代码报告、打包 |
